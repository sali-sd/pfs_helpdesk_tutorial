# PFS Helpdesk Tutorial

**Website:** [https://sali-sd.github.io/pfs_helpdesk_tutorial](https://sali-sd.github.io/pfs_helpdesk_tutorial)

Welcome!  This webpage provides an introduction to the Subaru Prime Focus Spectrograph data reduction pipeline (PFS DRP) and inspection process. It also includes guidance on using the Science Platform for analyzing data products.

We welcome comments and contributions to improve this documentation. If you would like to contribute, please follow these steps:

1. **Create a branch** and edit the Markdown files (`*.md`) in the `docs/` folder.
2. **Submit a pull request** with your changes.

The website is built and deployed automatically via GitHub Actions when changes are merged — there is no need to compile or commit the `site/` folder.

All updates will be reviewed for consistency before being merged.  
Thank you for your contributions!
